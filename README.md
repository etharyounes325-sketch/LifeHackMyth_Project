## 1. Project Overview
This is a native Android application developed using Kotlin [2]. It helps users distinguish between viral life hacks and common myths through an interactive flashcard-style quiz. The app features a welcome screen, a looping quiz logic, and a score calculation system.

## 2. Technical Features & Implementation
* **Iteration (Looping):** The app uses a loop-based system to iterate through the collection of life hacks, ensuring a smooth transition between questions.
* **Explicit Intents:** Used to transfer the final score data from the Quiz Activity to the Final Score screen for personalized feedback.
* **Logging:** I implemented Android Logging (`Log.d` and `Log.i`) to track application states and ensure the logic flows correctly during development [1].
* **GitHub Actions:** Configured automated builds using the project's YAML workflow to ensure code stability across different environments.
