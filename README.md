# Life Hack vs Urban Myth - Quiz Application
**Student Name:** Ethar Aboyounes  
**Student Number:** ST10539495

## 1. Project Overview
This is a native Android application developed using Kotlin. It helps users distinguish between viral life hacks and common myths through a flashcard-style quiz.

## 2. Technical Features
* **Iteration:** Used a loop-based system to navigate through the list of hacks.
* **Explicit Intents:** Used to transfer the final score from the Quiz activity to the Score screen.
* **Logging:** Implemented `Log.d` and `Log.i` to monitor application states and transitions.
* **GitHub Actions:** Configured automated builds to ensure code stability.
